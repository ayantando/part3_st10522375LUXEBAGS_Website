  ## Part 3 – E-commerce Functionality and Final Improvements

### Product Catalogue and Gallery
- Improved the product catalogue using JavaScript.
- Added dynamic product display and product search functionality.
- Implemented Add to Cart functionality.
- Added browser-based notifications when products are added to the cart.
- Improved the product image gallery with an interactive lightbox.
- Added image captions and keyboard interaction.

### Shopping Cart
- Replaced the original static cart content with dynamic cart functionality.
- Implemented Local Storage to save selected products.
- Added quantity updating functionality.
- Added the ability to remove products from the cart.
- Implemented automatic subtotal, delivery fee and total calculations.
- Added a delivery fee of R100 for non-empty carts.

### Checkout Functionality
- Improved the checkout page structure and layout.
- Added customer information and delivery information fields.
- Added payment method selection and required form validation.
- Connected the checkout page to the shopping cart.
- Implemented dynamic order summaries.
- Added demo order number generation.
- Saved the latest order information using Local Storage.
- Redirected customers to a dedicated order confirmation page after placing a demo order.

### Order Confirmation
- Created a new `order-confirmation.html` page.
- Added `order-confirmation.js` to display saved order information.
- Added order number, order date, product details, quantities, delivery fee and total.
- Added a Continue Shopping link.

### Enquiry and Contact Forms
- Improved the enquiry form with required fields and input validation.
- Added South African phone number validation.
- Added character limits for customer input.
- Implemented JavaScript form submission handling.
- Added a confirmation message and email hand-off using a mailto link.
- Tested the enquiry form functionality.
- Tested the contact form functionality.

### SEO Improvements

### Responsive Design and User Experience

### Documentation and Version Control

### Known Issue
- The hamburger navigation menu has been added to the pages, but its functionality has only been confirmed on the homepage. The remaining pages still require a final navigation check and correction.

### Technical Notes
- Local Storage is used for shopping cart and demo order information.
- The checkout process is a front-end demonstration and does not process real payments.
- Email forms use the customer's email application rather than a server-side email system.
